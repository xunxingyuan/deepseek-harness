# G1brain 文档图片与登录过期

[English](guide.md) | 中文

## 变更

文档上传通过现有静态资源服务保留 DOCX 正文图片、XLSX 工作表图片和 Markdown 本地图片引用。含图片的上传现在要求真实的 G1brain OAuth token 和经认证的用户 ID。图片格式不支持、本地文件缺失、路径越界或静态链接不可用时，在提交该文档的 Markdown 前报错。旧版 XLS 图片须先转换为 XLSX。不会自动改写已有文档。

桌面 OAuth 登录会以当前进程内凭据替换宿主。有效期到期或认证请求返回 HTTP/业务码 401 时，直接返回登录页并停止后续认证操作，无需再次确认。本地文件和会话保留。开发登录仍不验证 G1brain 身份，也不提供静态资源 token。

## 迁移

1. 在桌面登录页的「连接设置」中填写服务地址、clientId 和 clientSecret，再使用 G1brain 账号登录。保存密钥即启用 OAuth；留空保留已配置密钥，密钥由系统加密且不回显。旧的纯地址配置仍可读取；加密配置复制到其他设备或账号后可能须重新配置。密钥不打入安装包。外部部署仍可使用 OAuth 环境配置；独立宿主上传图片还须配置 `G1BRAIN_USER_ID`。
2. 图片分类不是现有根分类 `11` 时，设置集成的 `resourceCategoryId`。资源服务须返回永久、匿名可读的同源路径；不会向图片 URL 添加 token。只能上传符合该服务器静态访问策略的资料。
3. 将含图片的 XLS 另存为 XLSX；不支持的图片格式转换为 PNG/JPEG/GIF/WebP/BMP，本地图片使用标准 Markdown 图片语法。Excel 数据进入表格服务时，仍须选择向量文档库保存图片说明。
4. 修复旧文档时重新导入原件，重试前核对已有文档记录。保留图片的导入不会复用旧的纯文本回执；后续文档步骤失败可能留下已接受的图片，不会自动删除。
