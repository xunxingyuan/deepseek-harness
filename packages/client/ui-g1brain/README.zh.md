# G1brain 工作台界面

[English](README.md) | 中文

## 概述

桌面配置默认启用此客户端插件，登录后打开 G1brain 页面。首页把已连接服务中的本体集合和文档库绘为围绕资产类型的资源节点，显示实际数量及可用显示名；连线只表示资源归属，不表示本体关系。图库可展开完整目录，但不取代首页的图示；页面不推断领域数或文档数。点击已有本体会预选该集合并进入完善流程；新建和完善入口也可打开准备表单。随后选择领域、新建或已有文档库，并指定本地材料目录。已有集合和领域若提供显示名，选择器优先显示易读名称，并在括号中保留 API 名称；实际选择值与会话绑定仍使用 API 名称。不会另建任务记录；选定目录成为 Harness 工作区，由会话承载工作。

## 使用

页面通过宿主 G1brain 服务读取已有资源名称。没有 API 凭据时，总览会显示资源暂不可用；新建本体入口仍可打开表单，填写新资源名称并选择本地目录来准备会话，完善入口不可用。材料目录既可通过系统选择器选取，也可粘贴本地绝对路径；创建工作区时会验证路径。「进入 Harness 会话」会新建会话、在宿主绑定所选目标及目录，并生成要求先盘点资料、给出方案的草稿。草稿还会提示智能体先确认 MD 切片及片段/索引处理完成，再宣称上传文档可检索。进入会话本身不会创建本体、上传文件或提交任务。侧栏的 G1brain 入口可从会话返回此页面。

页面会等待会话引用就绪，再准备草稿并跳转。失败时保留表单，分别提示目录访问、会话创建、目标绑定或草稿初始化问题；解决对应步骤后可重试。

新本体和新领域输入作为显示名；宿主只解析一次接口标识，并将已保存的映射加入草稿。优化流程排除系统 schema/shared 领域，只有一个业务领域时自动选中；存在多个业务领域时仍需明确选择。进入操作会说明缺少的字段、加载失败或没有业务领域的情况；本体、领域、文档库和材料目录均有效后即可进入。切换集合立即使上一个领域失效，并忽略其他集合迟到的响应。

## 理解此包

## 模型体验

### 已准备的会话草稿

#### 模型看到的内容

浏览器插件不注册工具。准备的草稿仅在用户于 `Session` 中提交后才成为普通用户消息，并要求模型在进度、提问和最终结果中遵循当前请求的语言。宿主依据持久绑定，将限定范围的 G1brain 工具加到该会话智能体。草稿允许在所选资源内直接执行非删除操作；删除和可能移除内容的替换导入须逐次取得 Harness 审批，不再额外发起聊天确认。

#### Token 影响

提交前不消耗模型 Token。提交后，草稿文本会加入请求。

#### KV Cache 影响

提交前不改变缓存；提交后的文本接在已有请求前缀之后。

## 已知限制与暂缓工作

<a id="known-limitations-and-deferred-work"></a>

- 选择已有资源需要连接 G1brain 服务。开发模式登录并非真实用户身份校验；开发写入使用配置的测试身份。
- 进入会话后目标固定；要处理其他资源，需返回页面新开会话。
